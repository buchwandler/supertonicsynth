# SupertonicSynth

SupertonicSynth provides a strict atomic `SupertonicRuntime.synthesize` API alongside the chunk-composing `synthesize_text` convenience API. Model and voice discovery reads catalog metadata without installing assets or opening runtime sessions. The [architecture documentation](architecture.md) describes these boundaries and how unknown model capacity is represented.
